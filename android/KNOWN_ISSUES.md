## 已修复记录

### ✅ 横屏时书本整体偏右下（2026-10-18 销账）

| 项 | 内容 |
|---|---|
| **现象** | 手机横屏（landscape）打开画册，书本没有居中，整体偏右下 |
| **根因** | 壳层横屏补偿系数的取值与实际屏幕比例不匹配，书本盒子的水平/垂直锚点算到了偏右下的位置 |
| **修法** | `_shell/layout.js` 按横屏比例做偏移补偿（2026-10-12 首版，后续随屏幕比例修正系数） |
| **验证** | 2026-10-18 **在原病机（荣耀 400 Pro）上复测通过**：横屏打开任意画册，书本左右上下留白对称，不再偏右下 |
| **备注** | 测试机 vivo Z5（Android 10 / Chrome 83）上一直复现不了，所以只能靠病机确认；现已确认 |

## 已知限制（不是缺陷，修不了也不必修）

1. **翻页动画里能看到下一页的内容（米色卡片）** —— 这是翻页的物理本质
   （封面掀开就该看到下一页），不是渲染 bug。此前排查并修掉的是
   **「先于内容出现的额外矩形 / 线 / 暗角」共 5 层**（书影、照片页底色、
   硬页阴影、书脊边缘阴影、舞台暗角），已全部修复（R48–R54）。
2. **旧内核（Chrome 83）兼容** —— `inset-inline` / `inset-block` 逻辑属性、
   `aspect-ratio`、`cqw` 单位都不支持，壳层 `_shell/cqwfix.js` 等已兜底；
   目标机（Android 14 新机）不受影响。
3. **教学画册的封面图可自行替换** —— 仓库源码里的教学画册封面是中性占位图
   （深色渐变 +「示例封面」）；想换成自己的封面图，替换
   `app/src/main/assets/books/guide/assets/photos/01-01.jpg` 后重新打包即可，
   版式与裁切会自动适配。
4. **调试签名** —— 工程内没有 release keystore，本仓库发布的 APK 为 debug 签名，
   安装时系统提示「未知来源 / 风险检测」属正常现象；仅供自用与测试，非应用商店分发。
